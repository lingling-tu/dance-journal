Sync with GitHub

Store your journal in your own private GitHub repo so it syncs across devices — automatically, every time you save. Everything stays yours.

One-time setup:
1. Create a private repo (e.g. dance-journal-data).
2. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate. Give it access to only that repo, with Contents: Read and write.
3. Paste your details below. The token is stored only in this browser and never leaves it except to talk to GitHub.
